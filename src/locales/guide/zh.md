# 用户指南

## 快速上手
Comic Fast 分为三个区域：左侧是**页面列表**，中间是**画布**（正在编辑的页面），右侧是**资源**，其下方显示所选对象的**属性**。
1. 在“分格”标签页中选择模板。
2. 把图片拖进分格。
3. 添加对话框和文字。
4. 保存（`Ctrl+S`）并导出。

## 页面
- **＋** 新建页面，**⧉** 复制页面，**🗑** 删除页面。拖动缩略图可调整顺序。
- “页面 → 自定义尺寸…”可设置任意尺寸（毫米、厘米、英寸或像素），也可选择 A4、漫画、条漫等常用规格。
- 选中页面（点击空白处）后可更改背景颜色。

## 分格
- “分格”标签页提供整页模板、单个分格和形状（圆形、菱形、六边形等）。单击或拖到页面上即可。
- 选中分格后可移动、缩放或旋转。在“形状 → 多边形”中可移动顶点；双击边可添加顶点。

## 图片
- “文件 → 导入图片…”（或把文件拖入窗口）。图片会出现在“图片”标签页。
- 把图片拖到分格上即可填入。选中分格后，在**图层**中可以铺满、适应、旋转和居中图片。
- “内置”标签页提供可直接使用的图片和剪影，可按名称搜索。
- “图片滤镜”可调整亮度、对比度、颜色、模糊等。“着色”会把剪影染成单一颜色。

## 对话框和文字
- “对话框”包括对话、思考、喊叫、低语和旁白。双击对话框即可输入文字。
- 在属性中可更改字体、大小、颜色和对齐方式。拖动尾巴尖端指向角色，拖动白色点可弯曲尾巴。
- “文字”包括文本框、标题和拟声词。

## 网点、纹理和渐变
可作为页面对象添加，也可在选中分格时作为分格内的**图层**添加。可用于背景、阴影或速度效果。拖动画布上的控制点可旋转和缩放。**渐变**会在画布上显示两个点：线性渐变表示起点和终点，径向渐变表示圆心和半径。每种颜色都有**透明度**滑块。

## 顺序、锁定和选择
- “编辑 → 置于顶层 / 置于底层”可改变对象的上下顺序。
- **锁定**（`Ctrl+L`）可防止误移动或误删除对象。
- `Ctrl+A` 全选，`Ctrl+D` 复制，`Delete` 删除。`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。

## 保存和导出
- “保存”会生成包含整个项目（含图片）的 `.cfast` 文件。
- “将页面导出为 PNG”保存当前页面；“全部导出为 PDF / CBZ”保存整部漫画。
- 一切都在您的电脑上完成，不会上传到任何服务器。

## 视图、主题和语言
- “视图”提供缩放、网格和对齐网格。`Ctrl+0` 使页面适合窗口。
- 右上角：**A** 调整界面文字大小，太阳/月亮切换浅色与深色主题，**地球图标**切换语言。
