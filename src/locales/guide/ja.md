# ユーザーガイド

## はじめに
Comic Fast の画面は 3 つのエリアに分かれています。左が **ページ一覧**、中央が **キャンバス**（編集中のページ）、右が **リソース** で、その下に選択中のオブジェクトの **プロパティ** が表示されます。
1. 「コマ」タブでテンプレートを選びます。
2. 画像をコマにドラッグします。
3. 吹き出しとテキストを追加します。
4. 保存（`Ctrl+S`）して書き出します。

## ページ
- **＋** でページを追加、**⧉** で複製、**🗑** で削除します。サムネイルをドラッグすると順番を変えられます。
- 「ページ → サイズを指定…」では、mm・cm・インチ・ピクセルで自由にサイズを決めたり、A4・漫画・ウェブトゥーンなどの定番サイズを選べます。
- ページを選択（何もない場所をクリック）すると背景色を変更できます。

## コマ
- 「コマ」タブには、ページ全体のテンプレート、単独のコマ、図形（円・ひし形・六角形など）があります。クリックまたはドラッグでページに置きます。
- コマを選択すると移動・サイズ変更・回転ができます。「形 → 多角形」では頂点を動かせ、辺をダブルクリックすると頂点が増えます。

## 画像
- 「ファイル → 画像を読み込む…」（またはウィンドウにファイルをドロップ）。読み込んだ画像は「画像」タブに並びます。
- 画像をコマにドラッグすると中に入ります。コマを選択して **レイヤー** で、全面表示・全体表示・回転・中央配置ができます。
- 「付属」タブにはすぐ使える画像とシルエットがあり、名前で検索できます。
- 「画像フィルター」で明るさ・コントラスト・色・ぼかしなどを調整できます。「染める」はシルエットを単色にします。

## 吹き出しとテキスト
- 「吹き出し」にはセリフ・思考・叫び・ささやき・ナレーションがあります。吹き出しをダブルクリックして文字を入力します。
- プロパティでフォント・サイズ・色・配置を変更できます。しっぽの先端をドラッグしてキャラクターに向け、白い点で曲げます。
- 「テキスト」にはテキストボックス、タイトル、擬音があります。

## トーン・テクスチャ・グラデーション
ページのオブジェクトとして、またはコマを選択して **レイヤー** として追加できます。背景、陰影、スピード感の演出に使えます。キャンバス上のハンドルをドラッグして回転・拡大縮小できます。**グラデーション**にはキャンバス上に2つの点が表示され、線形では開始と終了、放射状では中心と半径を表します。すべての色に **透明度** スライダーがあります。

## 重なり順・ロック・選択
- 「編集 → 最前面へ／最背面へ」で重なり順を変えます。
- **ロック**（`Ctrl+L`）で、うっかり動かしたり削除したりするのを防げます。
- `Ctrl+A` で全選択、`Ctrl+D` で複製、`Delete` で削除。`Ctrl+Z` で元に戻し、`Ctrl+Shift+Z` でやり直します。

## 保存と書き出し
- 「保存」はプロジェクト全体（画像を含む）を `.cfast` ファイルに保存します。
- 「ページを PNG で書き出す」は現在のページを、「すべて PDF／CBZ で書き出す」はコミック全体を保存します。
- すべてお使いのコンピューター上で行われ、サーバーには何も送信されません。

## 表示・テーマ・言語
- 「表示」にはズーム、グリッド、グリッドへの吸着があります。`Ctrl+0` でページをウィンドウに合わせます。
- 右上：**A** で画面の文字サイズ、太陽／月でライト・ダークテーマ、**地球儀** で言語を切り替えます。

## Comic Fast を気に入っていただけたら
役に立ったと感じたら、「ヘルプ → プロジェクトを応援」から支援できます。まったくの任意です。
