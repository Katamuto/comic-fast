# 사용 설명서

## 시작하기
Comic Fast는 세 영역으로 나뉩니다. 왼쪽은 **페이지 목록**, 가운데는 **캔버스**(편집 중인 페이지), 오른쪽은 **리소스**이며 그 아래에 선택한 개체의 **속성**이 표시됩니다.
1. '컷' 탭에서 템플릿을 고릅니다.
2. 이미지를 컷으로 끌어다 놓습니다.
3. 말풍선과 텍스트를 추가합니다.
4. 저장(`Ctrl+S`)하고 내보냅니다.

## 페이지
- **＋** 는 페이지 추가, **⧉** 는 복제, **🗑** 는 삭제입니다. 썸네일을 끌어 순서를 바꿀 수 있습니다.
- '페이지 → 사용자 지정 크기…'에서 mm, cm, 인치, 픽셀 단위로 원하는 크기를 정하거나 A4, 만화, 웹툰 같은 일반 규격을 고를 수 있습니다.
- 페이지를 선택(빈 곳 클릭)하면 배경색을 바꿀 수 있습니다.

## 컷
- '컷' 탭에는 페이지 전체 템플릿, 단일 컷, 도형(원, 마름모, 육각형 등)이 있습니다. 클릭하거나 끌어서 페이지에 놓으세요.
- 컷을 선택하면 이동, 크기 조절, 회전을 할 수 있습니다. '모양 → 다각형'에서는 꼭짓점을 옮길 수 있고, 변을 두 번 클릭하면 꼭짓점이 추가됩니다.

## 이미지
- '파일 → 이미지 가져오기…'(또는 창에 파일 끌어다 놓기). 가져온 이미지는 '이미지' 탭에 나타납니다.
- 이미지를 컷 위로 끌면 컷이 채워집니다. 컷을 선택한 상태에서 **레이어**로 덮기, 맞춤, 회전, 가운데 맞춤을 할 수 있습니다.
- '기본 제공' 탭에는 바로 쓸 수 있는 이미지와 실루엣이 있으며 이름으로 검색할 수 있습니다.
- '이미지 필터'로 밝기, 대비, 색상, 흐림 등을 조정합니다. '물들이기'는 실루엣을 한 가지 색으로 칠합니다.

## 말풍선과 텍스트
- '말풍선'에는 대사, 생각, 외침, 속삭임, 내레이션이 있습니다. 말풍선을 두 번 클릭해 글을 입력하세요.
- 속성에서 글꼴, 크기, 색, 정렬을 바꿉니다. 꼬리 끝을 끌어 캐릭터를 가리키고, 흰색 점으로 꼬리를 휘게 합니다.
- '텍스트'에는 텍스트 상자, 제목, 의성어가 있습니다.

## 패턴, 텍스처, 그라데이션
페이지 개체로, 또는 컷을 선택한 상태에서 컷 안의 **레이어**로 추가할 수 있습니다. 배경, 음영, 속도감 표현에 쓰세요. 캔버스의 핸들을 끌어 회전하고 크기를 조절합니다. **그라데이션**은 캔버스에 두 점이 표시되며, 선형에서는 시작과 끝, 방사형에서는 중심과 반지름을 나타냅니다. 모든 색에는 **투명도** 슬라이더가 있습니다.

## 순서, 잠금, 선택
- '편집 → 맨 앞으로 / 맨 뒤로'로 겹치는 순서를 바꿉니다.
- **잠금**(`Ctrl+L`)은 실수로 개체를 옮기거나 지우는 것을 막아 줍니다.
- `Ctrl+A` 모두 선택, `Ctrl+D` 복제, `Delete` 삭제. `Ctrl+Z` 실행 취소, `Ctrl+Shift+Z` 다시 실행.

## 저장과 내보내기
- '저장'은 프로젝트 전체(이미지 포함)를 `.cfast` 파일로 저장합니다.
- '페이지를 PNG로 내보내기'는 현재 페이지를, '전체를 PDF / CBZ로 내보내기'는 만화 전체를 저장합니다.
- 모든 작업은 내 컴퓨터에서 이루어지며 서버로 아무것도 업로드되지 않습니다.

## 보기, 테마, 언어
- '보기'에는 확대/축소, 격자, 격자에 맞춤이 있습니다. `Ctrl+0`은 페이지를 창에 맞춥니다.
- 오른쪽 위: **A**는 화면 글자 크기, 해/달은 밝은·어두운 테마, **지구본**은 언어를 바꿉니다.

## Comic Fast가 마음에 드셨나요?
유용하셨다면 '도움말 → 프로젝트 후원'에서 응원할 수 있습니다. 전적으로 선택 사항입니다.
